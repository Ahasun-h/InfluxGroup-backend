Vue Analytics Tracking Test

This page demonstrates the analytics tracking that will be integrated into your Vue frontend.

Status: Click a button to test analytics tracking

📊 How it works:

  1. Each button simulates a page visit on your Vue frontend
  2. The tracking service sends data to Laravel backend API
  3. Laravel stores visitor and page view information
  4. View collected data at /admin/analytics/website

🔧 Integration in Vue Project:

  • src/services/analyticsTracking.js - Core tracking service
  • src/composables/useAnalytics.js - Vue composable for easy use
  • src/App.vue - Automatic route tracking enabled
  • API_CONFIG.baseURL - Points to Laravel backend

🚀 Next Steps:

  1. Start Vue development server: npm run dev
  2. Visit different pages in your Vue application
  3. Check /admin/analytics/website for collected data
